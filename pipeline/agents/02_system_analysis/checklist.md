# Чек-лист самопроверки (System Analysis)

- [ ] `boundaries` описывают внешние системы/акторов (внутри/снаружи).
- [ ] Каждая роль имеет список разрешений.
- [ ] Каждый сценарий: `id` (US-001…), актор из ролей, шаги, ожидаемый результат.
- [ ] Сценарии покрывают все must-FR из requirements.json.
- [ ] `entities` следуют из сценариев (не выдуманы).
- [ ] Допущения системного уровня явно перечислены.
- [ ] Нет API-проектирования (paths, методы), БД-таблиц, UI-экранов.
- [ ] Ответ — ТОЛЬКО JSON по схеме.
