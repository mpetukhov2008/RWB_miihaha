# Чек-лист самопроверки (Architecture API)

- [ ] Каждая операция: уникальный `operationId`, `method`, `path`.
- [ ] У каждой операции есть `tags` (хотя бы один).
- [ ] Формат ошибок единый: `error_schema: "ProblemDetails"` у всех операций.
- [ ] Каждая must-FR имеет минимум одну операцию с `requirement_ids: [FR-...]`.
- [ ] `auth` проставлен по ролям из system-analysis.
- [ ] Сущности соответствуют системной модели (не выдуманы).
- [ ] request/response — типизированные схемы.
- [ ] Ответ — ТОЛЬКО JSON по схеме.
