# Geo-модуль: PostGIS

Модуль работы с геоданными платных зон. Копируется в
`generated/<case>/backend/Geo/` агентом 05.

## Состав

- `Geo/GeoService.cs` — поиск ближайшей зоны по координатам;
- `Geo/CsvZoneImporter.cs` — импорт зон из CSV (или JSON) в PostGIS;
- `db/init/01_postgis.sql` — включение расширения PostGIS.

## Адаптер провайдера

Чтобы пайплайн оставался универсальным, гео-логика вынесена за
`IParkingProvider` (см. `templates/mocks/`): конкретный источник данных
(городской JSON, CSV) подставляется через интерфейс, чтобы тесты и демо
работали на mock-данных.
