# Продуктовое описание

## Обзор

Парковочное приложение — MVP-решение для управления платной парковкой. Приложение позволяет водителю быстро начать и завершить парковочную сессию, автоматически фиксировать тариф и длительность, получать уведомления о статусе сессии и просматривать историю парковок. Администратор управляет платными зонами, тарифами и сессиями.

## Целевая аудитория

- **Водители** — пользователи, которые паркуются в платных зонах и хотят удобно управлять парковочными сессиями.
- **Администраторы** — сотрудники, которые управляют платными зонами, тарифами и сессиями.

## Ключевые возможности

### Для водителя

1. **Определение платной зоны** — приложение автоматически определяет по геолокации, находится ли водитель в платной зоне, и показывает тариф до начала сессии.
2. **Управление сессией** — быстрый старт и завершение парковочной сессии с автоматическим фиксированием времени, зоны и тарифа.
3. **Уведомления** — push-уведомления о старте сессии, скором окончании оплаченного времени и превышении времени.
4. **История парковок** — просмотр всех завершённых сессий с датой, зоной, длительностью, стоимостью и статусом.
5. **Mock-оплата** — имитация оплаты в MVP: фиксированная сумма при старте, пересчёт по факту при завершении.

### Для администратора

1. **Управление зонами** — создание и редактирование платных зон с тарифами.
2. **Просмотр сессий** — список активных сессий и история по зоне.
3. **Безопасный доступ** — доступ только для роли администратора, все операции аутентифицированы.

## Цели продукта

1. Дать водителю возможность быстро начать и завершить парковочную сессию.
2. Автоматически фиксировать тариф и длительность сессии.
3. Информировать водителя о начале, окончании и превышении времени.
4. Дать админу панель для управления зонами, тарифами и сессиями.

## Ограничения MVP

- **Mock-оплата**: реальная платёжная интеграция не входит в MVP.
- **Локальная корпоративная модель**: приложение работает без доступа в интернет.
- **Одна активная сессия на водителя**: одновременное ведение нескольких сессий не поддерживается.
- **Тарифы задаются админом вручную**: динамическое изменение тарифов не поддерживается.

## Риски

1. **Неточность геолокации** — в плотной застройке водитель может получить неверное определение зоны.
2. **Задержка уведомлений** — таймеры уведомлений чувствительны к фону приложения, уведомления могут задерживаться.

## Метрики успеха

- **Время отклика API**: 95-й перцентиль < 300 мс.
- **Удобство использования**: время начала сессии < 30 секунд.
- **Надёжность**: 99% сессий завершаются без ошибок.
- **Уведомления**: 95% уведомлений доставляются вовремя.
