# Известные ограничения

## Ограничения MVP

1. **Mock-оплата**: реальная платёжная интеграция не входит в MVP. Оплата имитируется фиксированной суммой при старте и пересчётом по факту при завершении.
2. **Локальная корпоративная модель**: приложение работает без доступа в интернет.
3. **Одна активная сессия на водителя**: одновременное ведение нескольких сессий не поддерживается.
4. **Тарифы задаются админом вручную**: динамическое изменение тарифов не поддерживается.

## Допущения (Assumptions)

1. **Водитель даёт согласие на геолокацию**: приложение требует разрешения на доступ к геолокации. Без согласия определение зоны невозможно.
2. **Одна активная сессия на водителя**: система не поддерживает несколько одновременных активных сессий для одного водителя.
3. **Тарифы задаются админом вручную (без динамики)**: тарифы не изменяются автоматически в зависимости от времени суток, спроса и других факторов.

## Риски

### RK-01: Неточность геолокации

- **Описание**: геолокация неточна в плотной застройке — водитель может получить неверное определение зоны.
- **Влияние**: неверное определение зоны может привести к ошибочному началу сессии или невозможности начать сессию в платной зоне.
- **Митигация**: рекомендуется проверять название зоны перед началом сессии. В случае ошибки можно завершить сессию и начать заново.

### RK-02: Задержка уведомлений

- **Описание**: таймеры уведомлений чувствительны к фону приложения — уведомления могут задерживаться.
- **Влияние**: задержка уведомлений может привести к тому, что водитель не узнает о превышении времени вовремя.
- **Митигация**: рекомендуется держать приложение в фоне или периодически проверять статус сессии вручную.
