# Руководство пользователя

## Обзор

Приложение позволяет водителю быстро начать и завершить парковочную сессию в платной зоне, получать уведомления о статусе сессии и просматривать историю парковок. Администратор управляет зонами, тарифами и сессиями.

## Роли

- **Водитель** — оплачивает парковку, управляет сессией, смотрит историю.
- **Администратор** — управляет платными зонами, тарифами, просматривает сессии.

## Водитель

### Определение платной зоны (FR-001)

При открытии приложения приложение определяет по геолокации, находится ли водитель в платной зоне.

- **Вне платной зоны**: отображается сообщение «Вне платной зоны».
- **Внутри платной зоны**: отображается название зоны, тариф и кнопка «Начать сессию».

> **Важно**: для работы геолокации необходимо дать согласие на доступ к геолокации в настройках устройства.

### Активная парковочная сессия (FR-002)

1. Нажмите «Начать сессию» в платной зоне.
2. Система фиксирует время начала, зону и тариф.
3. После старта отображается таймер и текущая стоимость.
4. Повторный старт в той же зоне невозможен, пока активна сессия.
5. Для завершения нажмите «Завершить сессию» — фиксируется время окончания и итоговая стоимость.

> **Примечание**: одна активная сессия на водителя.

### Уведомления (FR-003)

Водитель получает push-уведомления:

- **О старте сессии** — сразу после начала сессии.
- **О скором окончании** — за 5 минут до окончания оплаченного времени.
- **О превышении времени** — сразу после истечения оплаченного времени.

> **Важно**: для получения уведомлений необходимо разрешить push-уведомления в настройках устройства. Уведомления могут задерживаться, если приложение находится в фоне.

### История парковок (FR-004)

В разделе «История» отображается список всех завершённых сессий, отсортированный по дате начала (новые сверху). Каждая запись содержит:

- Дату начала
- Зону
- Длительность
- Стоимость
- Статус

### Mock-оплата (FR-005)

В MVP оплата имитируется:

- При старте сессии создаётся платёжный слёб в статусе `pending`.
- При завершении сессии статус меняется на `paid` с итоговой суммой.

Реальная платёжная интеграция не входит в MVP.

## Администратор

### Admin-панель (FR-006)

Доступ к админ-панели только для роли администратора. Все операции аутентифицированы.

#### Управление зонами и тарифами

- Создание новой платной зоны с указанием тарифа.
- Редактирование существующих зон и тарифов.

#### Просмотр сессий

- Список активных сессий.
- История сессий по зоне.

## Безопасность (NFR-002)

- Доступ к админ-панели возможен только для роли администратора.
- Все операции выполняются только после успешной аутентификации.

## Производительность (NFR-001)

API отвечает не дольше 300 мс в 95% запросов.
