## API-тесты
- POST /api/v1/photo-reports — Загрузка фотоотчета и эталонного макета
  - Happy path: успешная загрузка фото и макета, статус «Соответствует макету» → 201
  - Ошибка: файл фото не в формате JPEG/PNG → 400
  - Ошибка: отсутствует эталонный макет → 400
  - Ошибка: заявка не найдена → 404
- GET /api/v1/photo-reports/{reportId}/result — Получение результата верификации фотоотчета
  - Happy path: результат верификации со статусом «Соответствует макету» и процентом схожести → 200
  - Happy path: результат верификации со статусом «Низкое качество» → 200
  - Ошибка: отчет не найден → 404
- POST /api/v1/video-analysis — Загрузка видеопотока и эталонного макета для анализа
  - Happy path: успешная загрузка видео 150 секунд и макета → 201
  - Happy path: успешная загрузка видео 300 секунд с двумя разными роликами → 201
  - Ошибка: длительность видео вне диапазона 150–300 секунд → 400
  - Ошибка: файл видео не в формате MP4 → 400
- GET /api/v1/video-analysis/{analysisId}/report — Получение отчета по временным меткам видеоролика
  - Happy path: отчет с временными метками start_time и end_time → 200
  - Happy path: отчет с несколькими вхождениями целевого ролика → 200
  - Ошибка: анализ не найден → 404
- POST /api/v1/video-cuts — Запуск автоматической нарезки видео
  - Happy path: успешная нарезка 15-секундного фрагмента → 201
  - Ошибка: временные метки некорректны (end_time < start_time) → 400
  - Ошибка: длительность фрагмента не равна 15 секундам → 400
- GET /api/v1/video-cuts/{cutId}/status — Получение статуса нарезки и ссылки на итоговый файл
  - Happy path: статус «Выполнено» и ссылка на MP4 файл в S3 → 200
  - Happy path: статус «В обработке» → 200
  - Ошибка: нарезка не найдена → 404
- GET /api/v1/integrations/status — Получение статуса интеграции с Kafka и S3
  - Happy path: статусы Kafka и S3 в норме → 200
  - Ошибка: недоступность Kafka → 503

## E2E-тесты
- Сотрудник загружает фотоотчет и получает результат верификации (SC-001)
  1. Открыть мобильное приложение (Android/PWA) и авторизоваться как сотрудник технической службы
  1. Перейти в раздел «Фотоотчеты» и выбрать заявку
  1. Загрузить фото рекламной конструкции (JPEG) и эталонный макет (PNG)
  1. Нажать кнопку «Запустить проверку»
  1. Дождаться завершения обработки
  1. Проверить, что отображается процент схожести и статус «Соответствует макету»
  1. Проверить, что фото автоматически привязано к заявке в списке
- Сотрудник загружает фото с низким качеством (SC-002)
