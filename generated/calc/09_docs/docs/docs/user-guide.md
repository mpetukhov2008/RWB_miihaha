# Руководство пользователя

## Обзор

Калькулятор позволяет ввести два числа и получить результат их суммы.

## Основные функции

### Ввод двух чисел (FR-001)

Пользователь может ввести первое и второе число через консольный интерфейс.

### Суммирование двух чисел (FR-002)

Система вычисляет сумму двух введенных чисел.

Примеры:
- При вводе чисел 2 и 3 система возвращает 5
- При вводе чисел -1 и 1 система возвращает 0

### Отображение результата (FR-003)

Пользователь видит результат суммы после ввода двух чисел.

## Поддержка типов чисел (NFR-001)

Система поддерживает ввод целых и дробных чисел, включая отрицательные.

## Обработка некорректного ввода (NFR-002)

При вводе нечислового значения система выводит сообщение об ошибке.

## Пример сессии

```
Введите первое число: 2
Введите второе число: 3
Результат: 5
```
