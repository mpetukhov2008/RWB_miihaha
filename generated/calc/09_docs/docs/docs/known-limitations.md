# Известные ограничения

## Допущения

1. Пользователь вводит числа через интерфейс (консоль, веб, GUI — не уточнено)
2. Результат суммы должен быть отображен пользователю
3. Поддерживаются целые и дробные числа, включая отрицательные
4. При некорректном вводе система должна выводить сообщение об ошибке

## Ограничения

- Калькулятор должен суммировать ровно два числа
- Не определено, какие типы чисел поддерживаются (целые, дробные, отрицательные) — по умолчанию поддерживаются целые и дробные числа, включая отрицательные
- Не определено, как обрабатывать некорректный ввод — по умолчанию выводится сообщение об ошибке
- Не определено, как должен выглядеть интерфейс ввода и вывода — по умолчанию консольное приложение
