# Руководство для разработчика

## Архитектура

Приложение состоит из следующих компонентов:

1. **main.py** — точка входа, обрабатывает ввод пользователя и выводит результат
2. **calculator.py** — модуль с функцией суммирования
3. **tests/** — модуль тестирования

## Структура проекта

```
.
├── main.py
├── calculator.py
├── requirements.txt
├── tests/
│   └── test_calculator.py
└── docs/
```

## Как добавить новую функцию

1. Создайте новую функцию в `calculator.py`
2. Добавьте тесты в `tests/test_calculator.py`
3. Обновите `main.py` для использования новой функции

## Тестирование

```bash
pytest
```
