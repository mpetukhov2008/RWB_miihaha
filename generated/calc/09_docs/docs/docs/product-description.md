# Описание продукта

## Назначение

Калькулятор — это простое консольное приложение, которое позволяет пользователю ввести два числа и получить результат их суммы.

## Целевая аудитория

Любой пользователь, которому нужно быстро посчитать сумму двух чисел.

## Ключевые возможности

- Ввод двух чисел (целых, дробных, отрицательных)
- Вычисление суммы
- Отображение результата
- Обработка некорректного ввода

## Технические характеристики

- Язык: Python
- Интерфейс: консольный
- Поддерживаемые типы чисел: целые, дробные, отрицательные
