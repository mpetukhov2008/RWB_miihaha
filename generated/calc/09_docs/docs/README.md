# Калькулятор суммы двух чисел

Простое консольное приложение, которое суммирует два числа и выводит результат.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Тестирование

```bash
pytest
```

## Использование

1. Запустите приложение.
2. Введите первое число.
3. Введите второе число.
4. Получите результат суммы.

## Поддерживаемые типы чисел

- Целые числа
- Дробные числа
- Отрицательные числа

## Обработка ошибок

При вводе нечислового значения система выводит сообщение об ошибке.
