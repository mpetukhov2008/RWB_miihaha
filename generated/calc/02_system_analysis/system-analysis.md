# Системный анализ

## Границы системы
**Внутри:** Логика ввода двух чисел, Логика суммирования двух чисел, Логика отображения результата, Логика обработки некорректного ввода
**Снаружи:** Пользователь, Внешний интерфейс (консоль, веб, GUI — не уточнено)

## Роли и разрешения
- **Пользователь**: Ввести первое число; Ввести второе число; Получить результат суммы; Получить сообщение об ошибке при некорректном вводе

## Сценарии использования
### US-001: Суммирование двух чисел
**Актор:** Пользователь
**Требования:** FR-001, FR-002, FR-003
**Шаги:**
1. Пользователь вводит первое число
1. Пользователь вводит второе число
1. Система вычисляет сумму двух чисел
1. Система отображает результат суммы
**Результат:** Пользователь видит результат суммы двух введенных чисел

### US-002: Обработка некорректного ввода
**Актор:** Пользователь
**Требования:** NFR-002
**Шаги:**
1. Пользователь вводит нечисловое значение
1. Система определяет некорректный ввод
1. Система выводит сообщение об ошибке
**Результат:** Пользователь видит сообщение об ошибке

## Сущности
- **Число** — Входное значение, вводимое пользователем (целое или дробное, включая отрицательные)
- **Результат** — Результат суммирования двух чисел
- **Сообщение об ошибке** — Сообщение, выводимое при некорректном вводе

## Допущения
- Пользователь вводит числа через интерфейс (консоль, веб, GUI — не уточнено)
- Результат суммы должен быть отображен пользователю
- Поддерживаются целые и дробные числа, включая отрицательные
- При некорректном вводе система должна выводить сообщение об ошибке

- Как обрабатывать некорректный ввод (не числа)?
