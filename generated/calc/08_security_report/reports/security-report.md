# Security Report

Проведён анализ безопасности на основе предоставленной архитектуры. Ключевые риски связаны с отсутствием аутентификации и авторизации на эндпоинте /calculations, отсутствием ограничений на входные данные (rate limiting, валидация диапазонов) и отсутствием механизмов защиты от повторных запросов (idempotency) на уровне API. В репозитории не обнаружено секретов, JWT-конфигурация не применима, так как аутентификация не настроена. Рекомендуется внедрить аутентификацию, валидацию входных данных и rate limiting.

## Findings
| Severity | Title | Status | Description |
|---|---|---|---|
| high | Отсутствие аутентификации и авторизации на эндпоинте /calculations | open | Операция POST /calculations имеет параметр auth: false, что означает отсутствие аутентификации. Это позволяет любому пользователю выполнять операции суммирования без проверки личности. В зависимости от бизнес-логики это может привести к злоупотреблению ресурсами или несанкционированному доступу к данным. |
| medium | Отсутствие валидации диапазонов входных данных | open | Поля first_number и second_number имеют тип number, но не указаны ограничения на диапазон значений (min, max). Это может привести к переполнению чисел, ошибкам в вычислениях или потенциальному злоупотреблению ресурсами при передаче экстремально больших значений. |
| medium | Отсутствие rate limiting на эндпоинте /calculations | open | Не указаны механизмы ограничения частоты запросов (rate limiting). Это может привести к DoS-атакам, когда злоумышленник отправляет большое количество запросов, исчерпывая ресурсы сервера. |
| low | Отсутствие idempotency key на уровне API | open | Хотя события имеют idempotency_key, на уровне API операции POST /calculations не указан механизм idempotency. Это может привести к дублированию операций при повторных запросах из-за сетевых сбоев или ошибок клиента. |
| info | Отсутствие секретов в репозитории | not-applicable | В предоставленной архитектуре не обнаружено секретов, ключей API или чувствительных данных. Это положительный результат. |
| info | JWT-конфигурация не применима | not-applicable | Так как аутентификация не настроена (auth: false), JWT-конфигурация не применима. Если в будущем будет добавлена аутентификация, необходимо будет проверить корректность JWT-конфигурации. |
