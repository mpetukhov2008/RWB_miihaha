# Данные кейса «Парковочный помощник»

В этой директории размещаются входные данные кейса (например, срез геоданных
платных зон в формате JSON).

На этапе MVP используется срез `spb.json` (или его уменьшенная копия) —
он подключается в профилировщик (`pipeline/profilers/`) и в сид
`generated/<case>/db/seed/`.

Полный файл (≈5,4 МБ) можно держать здесь или вынести в Git LFS.
Для тестов пайплайна используйте маленький срез, чтобы прогон был быстрым.
