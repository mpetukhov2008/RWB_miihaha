# Золотой эталон кейса «Парковочный помощник»

Здесь лежит эталон результата для сравнения (роль «участника C»).

Правила:
- НЕ копируйте файлы из `golden/` в `generated/` вручную — иначе потеряете
  честность демонстрации.
- Эталон обновляется только осознанно, через MR, после ревью.
- Сравнение прогона с эталоном выполняется скриптом/отчётом
  (`reports/`), а не ручным копированием.

Структура эталона повторяет структуру `generated/<case>/`:
`docs/`, `api/`, `ui/`, `backend/`, `frontend-admin/`, `db/`, `tests/`, `infra/`.
